# Morphogenetic Inference for Process-Aware, Self-Auditing Raman Spectralomics

Python code for the manuscript submitted to Digital Discovery.

## Quickstart

```bash
# from repo root
pip install -e .
python scripts/run_sweep.py --base_dir cells-raman-spectra
```

## Layout

- `src/raman_morpho/` importable library code
- `scripts/` runnable entry points
- `notebooks/` notebooks (multiple versions)
